# 공동 작업자 ddnwls — 별도 기여 기록

> **역할 구분:** [asnt39](https://github.com/asnt39)는 `asnt39/ppapeul` 저장소의 기존 소유자·관리자이며, [ddnwls](https://github.com/ddnwls)는 **관리자와 별개의 공동 작업자**이다. 이 문서는 **ddnwls가 기여한 작업만** 구분해 기록한다. `asnt39`의 기존 코드를 `ddnwls`의 독자적 작업으로 표시하지 않는다.

## 기여 인정 기준

- **확인된 GitHub 기여:** 각 커밋의 GitHub 작성자(author)가 `ddnwls`로 확인된 작업.
- **별도 저장소에서 수행한 개발:** `ddnwls/fast`에서 작성한 작업은 `asnt39/ppapeul`의 기존 관리자 작업과 분리하여 보존한다. 이 저장소에 자동으로 병합된 것으로 간주하지 않는다.
- **요청했지만 실행·커밋을 확인하지 못한 작업:** 사용자 요청 기록으로만 보존하며 구현 완료/직접 작성이라고 표기하지 않는다.
- **자동화 봇:** `github-actions[bot]`이 생성한 자동 이력 커밋은 봇의 실행 결과다. 자동화 워크플로를 설정한 사람과 봇이 쓴 커밋의 작성자는 구분한다.
- 공동 작업자의 기여는 파일 또는 기능을 단독 소유한다는 뜻이 아니며, 명시적인 증거가 없는 다른 사람의 코드까지 귀속시키지 않는다.

## 기존 관리자 asnt39의 작업과 분리

`asnt39/ppapeul`의 이전 원본 HTML 추가, 현재 호스팅 버전 반영, 레거시 프로토타입 제거, 기본 README 개편, 프로젝트 제출 파일 추가 등은 GitHub 기록상 **`asnt39` 작성 커밋**이다. 해당 작업을 `ddnwls`의 기여 목록에 포함하지 않는다.

## 향후 누적 기준

- 새 작업을 기록할 때 GitHub 계정/커밋 URL/변경 범위/테스트 상태를 함께 남긴다.
- `ddnwls`가 지시한 작업이라도 실제 커밋이 다른 사람의 계정으로 작성되었다면 **요청자/기획 기여**와 **코드 작성자**를 분리한다.
- `ddnwls`가 수행한 새 작업이 증명되면 이 문서에 기여 범위를 추가한다.
- 코드 자동 저장은 해당 작업이 GitHub에 커밋·푸시되었을 때만 감지할 수 있다. Codex 채팅 자체는 이 문서로 자동 동기화되지 않는다.
